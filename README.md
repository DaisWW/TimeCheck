# 钉钉考勤加班分析工具

用于分析钉钉考勤导出 Excel 的 Python 工具，可打包成 Windows EXE 供 HR 使用。

## 当前范围

- 读取钉钉导出的 `.xlsx` / `.xlsm` 考勤文件。
- 以 `每日统计` 作为每日考勤主表。
- 以 `原始记录` 查找每个人每天的首个和最后一个有效打卡。
- 输出包含加班明细、员工汇总、每日汇总、待补卡通知、待审核清单、异常数据、待人工确认和配置留痕的分析 Excel。

## 考勤规则（简版）

- **工作日**：09:00-10:00 弹性上班、弹性下班；09:00 前到按 18:00 下班，09:30 到按 18:30，10:00 及以后到按 19:00，不因迟到顺延。加班从标准下班后扣除 30 分钟晚餐，再按最后有效打卡计算。
- **休息日/节假日**：按首末有效打卡计算，扣除固定午休 12:00-13:30；晚餐默认不扣。班次含“休息”或日期在 `holiday_dates` 中时按非工作日处理。
- **节假日区分**：只有 `holiday_dates` 明确配置的日期归为法定节假日；其余“休息”班次统一归休息日，不按星期推断法定节假日。
- **公司放假**：单独维护 `公司放假.csv`，支持全天、上午、下午；对全员生效。放假部分免考勤、不计迟到或请假；实际工作按休息日加班并核对审批，法定节假日和原休息班次仍优先。
- **迟到和请假**：迟到按分钟统计；每月前 3 次、合计 30 分钟以内宽限，首次迟到 45 分钟时宽限 30、计扣 15 分钟。请假按审批实际区间逐日扣除固定午休，每天最多 7.5 小时，休息日不计请假；不按班次 09:30 裁切，不采用审批尾部标注小时数。审批可抵扣迟到，午休不计迟到；请假与加班分别保留，交 HR 审核是否同时计薪。
- **工资分类**：年假、调休不扣工资，事假计入扣工资请假；外出、出差计出勤，不计请假；病假、婚假和通用“请假”的工资分类尚未确认，单列并交 HR 审核。
- **审批**：工作日不要求加班审批；休息日和节假日需要审批，审批与实际相差超过 30 分钟时通知 HR 审核。
- **首末打卡**：原始有效打卡优先；不足两个不同打卡时间时，尝试每日统计中第 1/2/3 段打卡兜底，仍按首末有效卡计算，不扣中间离开时长。有效打卡不足时不计加班并列入待补卡；跨午夜按原始表的“考勤日期”归属。
- **输入报错**：缺表/缺列/重复列、未知审批、未知打卡结果、非法或无法完整解析的日期时间、重复员工日记录、无法归属的原始打卡、公式及错误单元格均报错。一次列出工作表、行号、字段、原始值和原因；该文件不生成统计结果，命令行退出码为 4。配置格式或类型错误退出码为 2。

完整规则、实际样本发现、支持/拒绝的格式和未覆盖边界见 [考勤规则核查](docs/attendance_rules_review.md)。

## 运行

在开发机双击根目录的 `run_attendance.bat`，或运行以下命令。报错后 BAT 会保留窗口。

```powershell
python -m attendance_analyzer.cli
```

命令行会批量分析 `input` 中所有 `.xlsx` 和 `.xlsm` 文件，并将结果写入 `output` 目录。文件名包含配置后缀 `_加班分析` 的已有结果文件会被跳过。同名的 `.xlsx` 和 `.xlsm` 会在开始处理前报错，请先重命名其中一个，避免结果覆盖。

同一员工每个自然月须使用一份完整考勤文件；迟到宽限在各文件内独立分配，不支持拆月后分别计算。

仍可只分析一个指定文件：

```powershell
python -m attendance_analyzer.cli "input\2026.5考勤.xlsx" -c config.csv
```

## 用 Excel 配置规则

基础规则只支持 CSV 配置。直接用 Excel 或 WPS 打开 `config.csv`，根据每行的中文“说明”修改“值”列，保存后重新运行即可，不需要改代码。`config.example.csv` 是完整备用模板，不会自动读取。

| 分类 | 配置项 | 值 | 说明 |
| --- | --- | --- | --- |
| 工作日 | 每日工作分钟 | 450 | 7.5小时，只填整数分钟 |
| 工作日 | 每月迟到宽限次数 | 3 | 每人每月最多宽限前3次 |
| 工作日 | 统计非工作日加班 | 是 | 开关填写“是”或“否” |
| 加班 | 取整方式 | 向下取整 | 也支持“向上取整”“就近取整” |
| 非工作日 | 法定节假日日期 | 2026-10-01;2026-10-02 | 多个日期用分号分隔；这里只是格式示例，需自行维护实际法定节假日 |

- 保留“分类、配置项、值、说明”四列表头以及配置项名称；说明文字可自行修改。
- 时间填写 `09:00` 或 `09:00:00`，兼容 Excel 保存后的 `9:00`；分钟和次数只填整数，不加“分钟”“小时”等单位，不填公式。
- 日期填写 `YYYY-MM-DD`，兼容 Excel 保存后的 `YYYY/M/D`。多个日期、关键字、前缀用分号 `;` 分隔，也支持中文分号和顿号。
- “法定节假日日期”“休息班次关键字”“无效打卡前缀”留空表示空列表；其他值不能为空。删除整行表示使用该项的内置默认值，不表示禁用该项；恢复默认建议从模板复制。
- 保存类型选择 **CSV UTF-8（逗号分隔）**；也兼容旧版中文 Windows Excel 保存的 GBK/GB18030 编码 CSV。不要保存成 `.xlsx` 后仅修改扩展名。
- 值类型错误、非法日期时间、负分钟数、重复或未知配置项都会报错，指出文件、行号和原始值，并停止统计；配置错误退出码为 2。

配置查找顺序为：当前目录 `config.csv` → EXE 所在目录 `config.csv`。只读取命中的一份，不合并；选中的 CSV 有错时直接报错并停止统计。也可通过 `-c 其他目录\config.csv` 指定一份 CSV，其他格式会报错。运行时会显示实际配置路径；未找到 CSV 时使用内置默认值并明确提示。

## 配置公司全天或半天放假

用 Excel/WPS 打开与当前基础配置同目录的 **`公司放假.csv`**，每行填写一个日期，保存为 CSV UTF-8（逗号分隔），再重新运行命令行。程序会显示本次读取的公司假文件路径及配置天数。只有“日期、时段、备注”表头而没有数据行，表示没有公司假；随项目提供的正式文件默认就是空表，以下日期仅为填写示例：

| 日期 | 时段 | 备注 |
| --- | --- | --- |
| 2026-10-16 | 全天 | 公司统一放假 |
| 2026-10-19 | 上午 | 上午活动 |
| 2026-10-20 | 下午 | 提前放假 |

`公司放假.example.csv` 提供同样的样例，修改为真实安排后才能复制到正式文件；程序不会自动读取样例文件。

- **全天**：覆盖钉钉正常工作排班，无需打卡，不计迟到、请假；实际来工作时按休息日加班规则，扣午休、按非工作日晚餐配置扣除，并要求审批。
- **上午**：午休结束后到岗，默认13:30；13:45到算迟到15分钟。下班按钉钉原班次，例如18:30，不按下午首卡顺延为19:00。午休开始前实际工作按休息日加班，原班次下班加工作日晚餐后另计工作日加班。例如09:30–22:00，上午计150分钟休息日加班，晚间19:00–22:00计180分钟工作日加班，共330分钟。
- **下午**：午休开始即可下班，默认12:00。之后到最后有效卡的工作按休息日加班，扣固定午休，晚餐沿用非工作日配置（默认不扣），不再叠加原工作日晚间加班。例如09:30–18:30计300分钟，至22:00计510分钟。
- **请假/外出**：只计算剩余正常工作时段。上午放假时按13:30至原班次下班裁切；下午放假时按弹性上班最早时间09:00至12:00裁切，仍采用审批区间，不各折算3.75小时。普通未配置公司假的日期继续使用原来的审批区间扣午休规则。
- **打卡**：半天公司假不会把有效卡不足的工作日自动放行；仍需成对有效卡计算加班，无卡且没有覆盖剩余工作时段的请假依据时仍列补卡。全天放假无打卡不列缺卡，有实际加班信号但有效卡不足时仍须补卡，审批不能代替打卡。原有首末卡规则继续适用，早退/旷工扣款仍未实现。
- **审批**：半天公司假只拿放假时段的实际加班与对应审批比较，保留原30分钟容差；当晚工作日加班不混入这次比较。工作日与休息日加班分别应用最小分钟和取整后相加。
- **优先级**：法定节假日和原“休息”班次保留整天非工作日规则，不因半天公司假变成另半天需要上班；公司假本身不归为法定节假日。关闭“统计非工作日加班”后，公司假加班也不计，正常工作日晚间部分仍统计。
- **校验**：日期必须包含4位年份，如`2026-10-19`或`2026/10/19`；时段只能填“全天、上午、下午”。重复日期（含上午/下午各一行）、错误日期、未知时段和缺列都会报出文件、行号、原值并停止统计。两段都放假请只填一行“全天”。

若明确使用 `-c 其他目录\config.csv`，只读取该目录的 `公司放假.csv`，不会混用当前目录的公司假。未找到基础配置时，才在当前目录、EXE目录按顺序查找公司假。文件缺失表示未配置；已有文件内容错误时直接报错，不跳过。

报表的总览和每日汇总分别汇总工作日、休息日加班；员工明细和加班明细另列公司放假时段、说明、加班分钟、迟到抵扣和当天应出勤分钟，“配置”页保留完整公司假安排。

## 目录结构

- `attendance_analyzer/`：分析源码包。
- `tests/`：自动化测试。
- `scripts/`：打包脚本。
- `input/`：待分析的钉钉 Excel；实际考勤文件只保存在本地，不提交到 Git。
- `output/`：分析结果；历史结果可放在 `output/archive/`，也不提交到 Git。
- `main.py`：命令行和 EXE 的顶层入口。
- `config.csv`：当前使用的中文规则配置；`config.example.csv`：完整备用模板。
- `公司放假.csv`：全员公司放假安排，默认空表；`公司放假.example.csv`：填写示例。

打包为 `.exe` 后，可使用发布目录的 `run_attendance.bat` 批量处理 `input`，或把单个钉钉 Excel 拖到 EXE 上运行。

## 设计

- `config.py`：读取中文 CSV 规则配置，并严格校验输入。
- `excel_reader.py`：把钉钉工作簿解析成类型明确的每日记录和原始打卡记录。
- `rules.py`：负责单日加班、迟到原始分钟和审批差异计算。
- `analyzer.py`：编排读取器和规则计算，并按员工/月分配迟到宽限。
- `report_writer.py`：写出最终分析工作簿。
- `cli.py`：命令行入口和批量处理流程。
- `main.py`：EXE 的顶层入口，避免直接打包包内模块时出现相对导入问题。

## 输出内容

输出 Excel 包含：

- `加班明细`：每天每人的加班计算结果，并包含计算说明。
- `员工汇总`：按员工汇总加班天数、分钟、小时、迟到次数、迟到原始分钟、宽限分钟、扣款迟到分钟，以及待补卡/待审核状态。
- `每日汇总`：按日期汇总加班人数、分钟、小时和迟到分钟，以及待补卡/待审核状态。
- `待补卡通知`：可直接交给 HR 的补卡通知清单；补卡后重新导出并再次运行。
- `待审核清单`：审批与实际打卡差异超过容差，或非工作日缺少可解析加班申请的记录，并标记是否需要通知 HR。
- `异常数据`：提示缺卡但有原始记录、有效打卡不足、审批差异等需要人工复核的数据。
- `待人工确认`：记录明确被规则排除的无效卡、补卡审批等业务提示。解析失败的输入会直接报错并停止该文件统计，修正后重跑；不会仅留提示就继续计算。
- `配置`：记录本次分析使用的关键规则。

## 打包 EXE

在 Windows 开发机安装 Python 后执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1
```

脚本安装依赖并构建控制台 EXE，生成 `dist\dingding-attendance`。将整个目录复制到 HR 的 Windows 电脑后运行，无需安装 Python。

发布目录包含 EXE、`run_attendance.bat`、正式 `config.csv` 和 `公司放假.csv`、对应填写模板及空的 `input/output` 目录。修改正式 CSV 后重新运行即可生效，模板不会自动读取。双击 BAT 批量处理 input；也可运行：

```powershell
dingding-attendance.exe "考勤.xlsx" -c config.csv -o output\结果.xlsx
```
