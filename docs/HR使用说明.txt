钉钉考勤统计 — HR 使用说明

一、首次使用
1. 适用于 Windows 10/11 的 64 位电脑，无需安装 Python，也不需要联网统计。
2. 右键 ZIP，选择“全部解压缩”，放在桌面等可写目录。请完整解压，不要在压缩包里直接运行。
3. 双击 dingding-attendance.exe，打开考勤统计窗口。

二、每月统计
1. 点击“选择考勤目录”，选择存有钉钉导出考勤文件的目录，也可事先将文件放入 input 目录。
   程序批量处理该目录第一层的全部 .xlsx / .xlsm，跳过 Excel 临时文件和已有分析报表，不扫描子目录。
   同一员工、同一月份必须在一份完整考勤文件中，不要拆分后分别统计。
2. 需要调整时，点击“编辑考勤规则”或“编辑公司放假”，在独立弹窗中修改后点击“保存并关闭”。
   需要使用其他位置的配置时，点击“选择配置文件”，选择 JSON 配置；公司假也保存在同一文件中。
   考勤目录、结果目录和配置路径会自动记住，下次打开继续使用；手动输入在开始或正常关闭时保存。
3. 点击“选择输出目录”，选择结果保存目录，再点击“开始统计”。
   忙碌条表示程序在处理，旁边显示实际已完成的文件数。
4. 完成后点击“打开本次结果”，查看总览、员工明细、待补卡通知、待审核清单。
   有待补卡、待审核记录时，HR 仍需根据报表清单处理。

三、配置
- “编辑考勤规则”：按标签页和中文说明修改；开关勾选，取整方式下拉选择。
- “编辑公司放假”：点击“添加日期或范围…”，用日历选择开始和结束日期，可跨月、跨年；单天起止选同一天。
  选择统一的全天/上午/下午和备注，再点击“加入逐日列表”。每一天都可单独改时段、备注或删除，日期旁显示星期。
  例如第一天下午、最后一天上午、中间全天：先统一选全天加入，再改首尾两天。
  范围包含首尾和周末，单次最多366天；已有日期会提示冲突，整批不加入，不会覆盖原安排。
  取消范围选择不改变列表；列表需点击“保存并关闭”才生效。没有任何行表示未安排公司放假。
  公司假不等于法定节假日；上午/下午的分界跟随考勤规则中的固定午休时间。
- 日期要有完整年份，如 2026-10-19。时长只填整数分钟，多个法定节假日用分号隔开。
- 规则和公司假统一保存在 config.json；程序自动维护格式，不用手工编辑文件或安装 Excel。
- 关闭弹窗时，未保存的修改可选择保存、放弃或继续编辑。错误输入会提示并保留弹窗，原文件不变。
- “配置模板”目录提供完整默认 JSON，不会自动读取它；恢复前请保留自己的规则和公司假安排。
- 正式基础配置缺失或有错时会停止统计，不会自动选用模板。
- 记住的配置移动或删除后，需点击“选择配置文件”重新定位；程序不会自动换成另一份规则。
- 旧 CSV/TOML 不再读取；旧版自定义设置请在新窗口核对录入，不要直接修改扩展名。

四、报错怎么办
- 窗口只弹出一次简短失败提示，完整错误保留在处理详情中，也会写入 logs 目录。
- 点击“复制详情”可复制所有信息，点击“打开本次日志”可查看/保留原文。
- 表单填写错误：按提示修改配置项或公司假日期，再保存；写入失败时原配置保留，可重试。
- JSON 文件损坏：选择有效配置或从配置模板恢复，勿把错误文件当成默认配置继续统计。
- 输入和输出必须是目录；旧版记住的是单个文件时，请点击对应的选择目录按钮重新选择。
- 考勤格式错误：按工作表、行号、字段、原始值找到钉钉导出内容，核对修正或重新导出。
  不认识的格式会报错，不会猜测后继续计算。
- 保存失败：查看详情；若文件被 Excel 占用，先关闭；若权限不足或空间不足，换一个保存目录后重试。
- 程序意外错误：保留本次日志供维护人员排查。
- 提示路径没有保存时，本次仍可统计，下次可能需重选。软件目录移动后请检查保存的路径。
- 批量遇错会停止，之前完成的文件保留，之后的文件尚未处理。

五、结果与日志
- 每次统计在所选结果位置新建“统计_日期_时间”目录，新旧结果分别保存。
- 报错不代表所有文件都成功；以窗口中的“已完成 X/Y 个文件”为准。
- 正在统计时请等结束后再关闭窗口；不要连续打开多个程序同时统计同一批文件。
- 本地日志含源数据及错误原值，请按公司的考勤资料管理方式保管。
- 查看结果可使用 Excel 或 WPS；编辑配置和统计本身无需安装 Office。
