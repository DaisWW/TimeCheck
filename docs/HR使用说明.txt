钉钉考勤统计 — HR 使用说明

一、首次使用
1. 适用于 Windows 10/11 64 位电脑，建议使用新版 Edge / Chrome。
   软件已自带运行环境，无需安装 Python、输入命令或联网安装；统计本身无需 Office。
2. 右键 ZIP，选择“全部解压缩”，放在桌面等可写目录。不要在压缩包里直接运行。
3. 双击解压目录中的“启动考勤工作台.vbs”，自动打开默认浏览器中的考勤工作台，后台不显示黑框。
   网页和计算服务都在本机运行，文件仅在本机复制，不上传到外部网站，不对局域网开放。
   重复双击会打开同一个服务，不会启动另一份计算程序。
   请保留目录中的全部文件，尤其是 runtime 文件夹；移动软件时整体移动，不要只复制启动文件。

二、每月统计
1. 点击“选择文件”多选，或从资源管理器拖入网页“原始考勤”区域；也可在资源管理器复制文件（Ctrl+C），回到统计工作台按 Ctrl+V 粘贴，支持多份文件。
   程序复制到软件旁的 input，保留源文件。
   遇同名文件可选择替换、跳过或取消。同一批选择中的不同来源文件重名时，请先重命名再导入。
   程序批量处理 input 第一层的全部 .xlsx / .xlsm，跳过 Excel 临时文件和已有分析报表，不扫描子目录。
   同一员工、同一月份必须在一份完整考勤文件中，不要拆分后分别统计。
2. 需要调整时，点击左侧“考勤规则”或“公司放假”切换设置页面，修改后点击底部“保存更改”。
   保存后留在当前页，可继续编辑；两个页面共用软件同目录的一份 config.json，下次打开继续使用，不需选择配置路径。
3. 点击“开始统计全部”，处理 input 中全部有效文件；选中哪些行不影响统计范围。
   进度条和已完成 X/Y 份显示实际完成的文件数。正在处理时按钮会禁用，结束后恢复。
4. 完成后右侧 output 列表自动显示并展开本次结果；双击报表打开，或选中批次后点击“打开所选”。
   可查看总览、员工明细、待补卡通知、待审核清单。
   有待补卡、待审核记录时，HR 仍需根据报表清单处理。

三、配置
- “考勤规则”：按标签页和中文说明修改；是否统计非工作日加班和取整方式使用下拉选择。
- “公司放假”：在“添加日期或跨天范围”中填写起止日期，或在日历上先点开始日、再点结束日，可跨月、跨年；单天起止选同一天。
  选择统一的全天/上午/下午和备注，再点击“加入逐日列表”。每一天都可单独改时段、备注或删除，日期旁显示星期。
  例如第一天下午、最后一天上午、中间全天：先统一选全天加入，再改首尾两天。
  范围包含首尾和周末，单次最多366天；已有日期会提示冲突，整批不加入，不会覆盖原安排。
  列表需点击“保存更改”才生效。范围尚未加入时会询问是否加入后保存。没有任何行表示未安排公司放假。
  公司假不等于法定节假日；上午/下午的分界跟随考勤规则中的固定午休时间。
- 日期要有完整年份，如 2026-10-19。时长只填整数分钟，多个法定节假日用分号隔开。
- 规则和公司假统一保存在 config.json；程序自动维护格式，不用手工编辑文件或安装 Excel。
- 切换页面或退出程序时，未保存的修改可选择保存并离开、放弃或继续编辑。错误输入会提示并保留当前页和草稿，原文件不变。
- 底部显示保存状态；“放弃修改”经确认后恢复已保存设置。没有修改时，保存和放弃按钮禁用。
- 如果另一个页面已修改同类配置，当前旧草稿会提示冲突并拒绝覆盖。请保留草稿内容，重新打开核对。
- “配置模板”目录提供完整默认 JSON，不会自动读取它；恢复前请保留自己的规则和公司假安排。
- 配置缺失或有错时，请修正软件旁的 config.json，不会自动换用另一份规则。
- 升级后固定读取当前软件旁的 input/output/config.json，不读取旧路径记录。
  之前用外部目录或自选配置的，请先把原考勤和配置复制到当前软件对应位置并核对。
- 旧 CSV/TOML 不再读取；旧版自定义设置请在新窗口核对录入，不要直接修改扩展名。

四、报错怎么办
- 处理详情默认收起，可点击查看；报错时自动展开并显示错误提示栏，完整错误也会写入 logs 目录。
- 点击“复制详情”可复制所有信息，点击“打开日志”可查看/保留原文。
- 表单填写错误：按提示修改配置项或公司假日期，再保存；写入失败时原配置保留，可重试。
- JSON 文件损坏：修正 config.json 或备份原配置后从配置模板恢复。
- input 和 output 必须是普通目录，不能被同名文件占用，也不能是目录联接或链接。
- 考勤格式错误：按工作表、行号、字段、原始值找到钉钉导出内容，核对修正或重新导出。
  不认识的格式会报错，不会猜测后继续计算。
- 保存失败：若文件被 Excel 占用，先关闭；若权限不足或空间不足，请完整解压到可写且空间充足的位置后重试。
- 程序意外错误：保留本次日志供维护人员排查。
- 无法启动：确认已右键 ZIP“全部解压缩”到可写目录，runtime 文件夹完整，并已设置默认浏览器。
  运行环境缺失时重新完整解压；若仍失败，请把系统弹窗内容及 logs 中的“启动失败”日志交给维护人员，不用自行安装 Python。
- 网页提示连接中断：重新双击程序打开新的工作台；当前页面未保存内容仍可保留核对。不要收藏旧的临时地址。
- 批量遇错会停止，之前完成的文件保留，之后的文件尚未处理。

五、结果与日志
- 每次统计在 output 内新建“统计_日期_时间”目录，新旧结果分别保存。
- input/output 均有列表，可按 Ctrl / Shift 多选后点击“移到回收站”，也可“清空…”整个对应列表。
  确认框会列出文件；清理整批结果包含其中全部文件。误删可从 Windows 回收站恢复。
  清理 input 中的副本不影响原始导出位置的文件。回收失败会提示，不会改为永久删除。
- 文件夹按钮可打开实际目录；在资源管理器中增删文件后，点击“刷新列表”。
- 运行期间禁止添加、清理、修改规则；移走公司历史数据前请按公司要求归档。
- 报错不代表所有文件都成功；以窗口中的“已完成 X/Y 个文件”为准。
- 点击左侧“退出程序”可结束空闲服务。直接关闭标签页后约3分钟自动结束空闲服务；统计中的任务继续完成后再退出，结果保存在 output。
- 刷新或关闭有草稿的页面时，浏览器会提示；配置需保存才会保留。重新双击程序即可恢复使用已保存配置和文件。
- 本地日志含源数据及错误原值，请按公司的考勤资料管理方式保管。
- 查看结果可使用 Excel 或 WPS；编辑配置和统计本身无需安装 Office。
