# HR 网页工作台与发布方式

Windows 10/11 64 位电脑完整解压发布 ZIP 后，双击 `启动考勤工作台.vbs` 即在系统默认浏览器打开工作台，无需安装 Python、运行依赖或输入命令。VBS 使用包内 pythonw 隐藏启动，服务只监听 `127.0.0.1` 随机端口；无需 WebView2、Office 或联网统计。建议使用新版 Edge / Chrome，网页资源全部内置。

## 启动和退出

| 使用场景 | 入口 | 环境要求 |
| --- | --- | --- |
| HR 打开工作台 | 双击 `启动考勤工作台.vbs` | 完整解压到可写目录，保留 runtime；使用现代浏览器 |
| AI / 自动化统计 | `一键统计考勤.bat` | 发布包使用内置环境；源码环境需 Python 和依赖；不打开网页、不等待按键 |
| 开发者调试 | `python main.py` | Python 3.11+ 和项目依赖 |
| 开发机发布 | `build_release.bat` | Windows 64 位、Python 3.11+ 及网络；验证后生成免安装 ZIP |

同目录通过操作系统文件锁保证只有一个服务，重复双击复用正在运行的服务。点击“退出程序”结束空闲服务；有计算或文件写入时拒绝退出。直接关闭标签页后约180秒无心跳则退出，运行中的统计会继续到结束，再按空闲条件退出。重开程序使用新的临时地址，文件和保存的配置保留。不要收藏临时网页地址。

启动文件缺少包内运行环境时，弹窗提示完整解压，不尝试使用 HR 电脑上的其他 Python 或临时联网安装。源码目录中存在开发打包脚本时，启动入口允许使用开发者 PATH 中的 Python。启动阶段的依赖导入、写入权限或浏览器错误通过系统弹窗提示，并保存启动失败日志。VBS 使用带 BOM 的 UTF-16，确保中文提示在 Windows Script Host 中正常显示。`logs/.client-session.json` 仅用于本机重复启动，退出删除；锁文件可以保留。

## 文件与统计

1. 固定读取软件同目录 `input/output/config.json`，不随当前工作目录变化，也不读取旧路径记录。移动部署时一起移动数据和配置；升级时先保留 HR 自定义配置。
2. 在“原始考勤”区域拖入或多选 `.xlsx/.xlsm` 文件。网页先校验整批名称和格式，再流式传到本机临时目录；完整传输后复制到 `input`，保留源文件。传输中断不会导入不完整副本。同名可替换、跳过、取消；确认期间目标变化则拒绝覆盖，替换失败保留原副本。
3. 左侧显示 input 第一层全部项目和参与状态。统计处理全部有效考勤，勾选只用于文件管理；子目录、临时文件及已有分析报表不参与统计。同一员工每月应使用一份完整文件。
4. 每次统计新建 `output/统计_日期_时间`，右侧按批次展示，完成自动展开最新批次。报表可双击打开，也可选中后“打开所选”。长中文文件名完整换行，显示大小和修改时间。
5. checkbox、Ctrl / Shift 支持多选。“移到回收站”或“清空”先显示具体清单，删除批次包含全部子文件；只管理 input/output 内普通项目，拒绝链接和目录联接，不回退到永久删除。输入清理不影响原始导出位置。
6. 正在导入、保存或统计时禁用相关操作，按钮保留明确状态。后台计算不阻塞页面；按实际完成文件数显示 X/Y。批量遇错停止，保留已成功报表，后续文件未处理。浏览器关闭不会打断后台写入。

无界面 BAT 固定处理自身目录的 input，结果直接写入 output，同名报表会覆盖；需要保留历史时先归档。UTF-8 输出和退出码便于自动化判断，详细口径见 README。

## 规则与公司放假

侧栏在统计工作台、考勤规则和公司放假三个页面间切换，选中态与顶部路径同步，共同维护唯一 `config.json`。全部22项规则以中文标签、说明和分组表单编辑；分钟/次数严格为整数，开关与取整方式为下拉选择。错误定位到字段并保留草稿。底部保存栏显示未保存状态，“保存更改”后留在当前页，可继续编辑和保存。

公司放假支持日期输入与中文日历：先点起日、再点止日，可以跨月年；统一选择全天/上午/下午及备注后加入逐日列表。范围包含首尾和周末，单次最多366天；已安排日期冲突时整批拒绝。每一天都能独立改日期、时段、备注或移除。范围尚未加入时保存会询问加入并保存、仅保存列表或继续编辑。空列表表示没有公司假。

切换页面或退出程序时，有修改会提示保存并离开、放弃或继续编辑；底部“放弃修改”经确认后重新读取已保存设置。保存前完整校验，使用临时文件原子替换，失败保留原文件及草稿并停留当前页。保存成功同步最新版本，允许连续编辑；保存时重读磁盘保留另一类最新设置，同类配置已被其他页面或外部程序改动时仍拒绝过期草稿覆盖。JSON 缺失或损坏直接报错，不回退到模板；旧 CSV/TOML 不读取。

网页仅改变配置编辑和展示方式，既有公司假、弹性出勤、审批、请假、迟到和加班规则保留。

## 错误呈现

| 场景 | 展示及处理 |
| --- | --- |
| 配置缺失、JSON 语法或字段错误 | 显示路径、字段及原因，语法错误含行列；禁止统计 |
| 表单日期、分钟、时段、重复日期等错误 | 设置页面保留输入，规则定位相应标签及字段 |
| 保存失败或同类配置版本冲突 | 明确提示未保存，保留原文件和草稿 |
| 上传格式、重名、传输或复制失败 | 显示原因和实际已添加数量，不导入截断文件，替换失败保留旧副本 |
| Excel 缺表列、未知审批、非法打卡或格式无法解析 | 提供文件、表、行、字段、原值和原因；失败文件不生成统计报表 |
| 输出占用、空间/权限、目录不合法 | 保留具体系统原因，提示关闭 Excel 或解压到可写位置 |
| 缺卡、审批差异、待确认工资分类 | 属于业务审核，报表中生成待补卡、待审核清单 |
| 网页与本机服务断开 | 遮罩提示重开程序，页面中的未保存内容保留 |
| 启动失败 | 系统错误弹窗及 logs 中的启动失败日志 |

处理详情默认收起，统计失败时自动展开并显示错误提示栏，可复制全部详情或打开日志。每次运行保存一份 UTF-8 日志，包含实际配置路径、结果目录、源数据错误及必要异常堆栈，按公司考勤资料要求保管。

## 本机服务范围

随机会话地址、严格 Host / Origin 校验、自定义请求头、API 白名单及 CSP 限定本机页面访问；不提供任意文件下载或路径打开。文件管理和结果打开限定管理目录。上传仅传到本机服务，不涉及云端。空闲监控与任务完成状态不依赖浏览器持续在线。

## 发布与验收

一键脚本安装开发环境依赖、校验正式 JSON、运行回归测试，再准备官方 CPython 3.13.16 x64 嵌入版和目标平台依赖，生成 `build/dingding-attendance.zip`。固定官方 ZIP 的 SHA-256，下载缓存使用前重新核对；依赖安装到临时环境，不复制开发机环境。包内 `_pth` 和 `-s` 启动参数隔离环境变量、系统及用户 Python 包，同时通过 site 加载 pywin32 的 DLL 引导。构建时在仅有 Windows 系统 PATH 的环境下实际加载 Excel、COM、回收站及应用模块。所有缓存和临时文件位于已被 Git 忽略的 `build/`，临时目录结束后清理。

ZIP 通过明确源码白名单加临时 runtime 生成并校验 CRC，包含 Python 代码、三个网页资源、VBS 和无界面入口、完整运行环境及许可证、正式 config.json、说明、独立默认模板及空 input/output/logs，避免夹带开发机考勤和报表。只有全部步骤成功才替换最终 ZIP；下载校验、依赖安装、环境缺失或 ZIP 损坏均保留原 ZIP，不把旧文件视为构建成功。接收电脑完整解压后直接使用 VBS 入口，首次也不需要联网。

自动化测试覆盖原计算与严格解析、文件管理、原子配置保存、日期范围、网页接口、上传中断与替换失败、并发锁、单实例复用、HTTP访问范围、隐藏启动失败提示及保存后连续编辑的版本更新；发布测试另覆盖运行环境完整性、下载和缓存校验、失败保留旧 ZIP 及清理临时目录。真实浏览器验证多文件导入、批量完成、规则错误保留、跨月范围和逐日时段；检查常规及900×620窗口的滚动与保存按钮。仅含有效 config.json 的新目录首次打开会创建 input/output，不会误报配置错误。

暗色界面已验证主页面、输入与结果列表、规则错误提示、未保存确认、公司假日历和逐日时段。常规及900×620窗口的空列表说明完整显示，无横向溢出；保存按钮可操作，配置保存后重新打开仍保留，原生日期与下拉控件使用暗色配色。

设置改为页面后，真实浏览器验证侧栏与顶部路径同步、切页保留文件选择、保存后留页和连续保存、错误阻止离页、放弃修改恢复、退出前草稿提醒，以及跨年范围和首尾半天安排。900×620下无横向溢出，底部字段可编辑，保存栏保持可见；返回工作台完成1份样本统计并生成报表。

此前源码 ZIP 已在本机完成解压验收：从其他工作目录调用 VBS 正常打开默认浏览器，重复启动复用会话，文件和配置固定在解压目录；通过网页导入样本并完成统计，回读员工汇总为加班60分钟、扣款迟到0分钟，退出后服务停止并清理会话记录。

免安装 ZIP 约18 MB，已解压到包含中文和空格的独立目录验收：PATH 仅保留 Windows 系统目录，PYTHONHOME/PYTHONPATH 故意指向不存在的位置，外网代理指向不可用地址。VBS 正常用包内 pythonw 打开浏览器，重复启动复用同一会话；BAT 从其他工作目录直接统计成功。网页完成样本导入与统计，回读结果为加班60分钟、扣款迟到0分钟；实际移入回收站成功且源文件保留，配置保存后刷新仍保留。开发 Python 3.11 和包内 Python 3.13 均通过165项自动化测试。验收在本机隔离运行环境完成，尚未在另一台实体电脑实测。
